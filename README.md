## 开源工具

| 项目 | 能帮你做什么 |
| --- | --- |
| [claude-writing-skills](https://github.com/xiaomoBoy/claude-writing-skills) | 用一组 Claude Code Skills 串起资料收集、文章优化与多平台发布。 |
| [github-publisher](https://github.com/xiaomoBoy/github-publisher) | 帮初次开源的人检查本地项目，再安全地发布到 GitHub。 |
| [visual-deck](https://github.com/xiaomoBoy/visual-deck) | 把选题或大纲做成图文混合的 HTML 演示稿，并可导出视频。 |
| [claude-pet](https://github.com/xiaomoBoy/claude-pet) | 在 macOS 桌面显示 Claude Code 的工作状态，等待操作或任务完成时提醒你。 |
